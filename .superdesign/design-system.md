# Doxa website design system

The public website uses a flat, photographic design. No eyebrow labels, gradients used as decoration, pill buttons, floating cards, or invented church statistics. A restrained image overlay is permitted for legible text on photographs.

## Typography

Use Arial, Helvetica, sans-serif, following the currently active heading overrides on thehouseest.com. Headings have medium weight, normal case, normal style, and close letter spacing around -0.055em. No serif or italic headings. Body text uses the same family with comfortable line height. Keep navigation and metadata comfortably legible.

## Palette and surfaces

- Paper #f8f6f1; muted paper #eae7df; dark ink #17213d.
- Royal blue #101f70 for primary actions. Restrained red #b52b37.
- Thin rules #dddcd6. Footer #101a35.
- Square corners, flat surfaces, no decorative shadows.

## Layout

Desktop shell: 1280px maximum with generous horizontal padding. Mobile padding 20px. Header height 104px desktop, 78px mobile. Full-width photographic hero with large, close-set sans-serif welcome on the left, introductory text, square visit button, text link and Sunday service time. Keep a clear photo visible on the right. Below it: flat directions strip, two-column introduction, simple ruled gathering rows, an invitation band, and a four-column footer.

The landing page always shows Daily message directly after the welcome/directions strip, reading the existing published home.dailyMessage text from Sanity. Daily message links in navigation jump to #daily-message. Preserve message paragraphs and show an availability notice if it cannot be loaded; do not insert a fallback Bible verse or invent a publication date. Article and gallery sections remain conditional; do not fabricate entries. Legacy 2025 programmes must not appear as upcoming events.

## Identity and facts
